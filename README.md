# Запуск программы

Для запуска нужен Python 3. Дополнительные библиотеки не требуются.

Откройте терминал в папке репозитория и перейдите в папку программы:

```bash
cd postfix_notation
```

Запустите `main.py`, передав выражение через аргументы командной строки:

```bash
python main.py "3 4 - 5 - 6 ~ 7 + 8 * 9 / 0 -"
```

Числа и операции разделяйте пробелами. Выражение заключайте в кавычки, чтобы командная оболочка не изменяла символы `*` и `~`.

Поддерживаются операции `+`, `-`, `*`, `/`, `~`. Отрицательные числа вводите со знаком минус, дробные — через точку.

Программа выводит состояние стека после каждого шага, затем ответ в формате `выражение = результат`. При неправильном вводе появляется сообщение с причиной ошибки.

## Ещё четыре примера запуска

```bash
python main.py "3 0 4 ~ 2 ~"
python main.py "2 2 + 4 - 4 ~ 2 3 * +"
python main.py "8 3 - 2 *"
python main.py "-2.5 4 + 3 /"
```

## Справка

```bash
python main.py --help
```

## Запуск тестов и проверка покрытия

Все команды выполняйте из папки `postfix_notation`.

Запуск тестов без дополнительных библиотек:

```bash
python -m pytest test_main.py
```

Чтобы узнать, какая часть программы выполняется во время тестов, установите `coverage`:

```bash
python -m pip install coverage
```

Запустите тесты с измерением покрытия:

```bash
python -m coverage run --branch --source=main -m unittest discover -s . -p "test_*.py"
```

`--source=main` измеряет покрытие файла `main.py`, а `--branch` дополнительно учитывает ветвления условий.

Выведите отчёт:

```bash
python -m coverage report -m
```

В столбце `Cover` указан процент покрытия, а в `Missing` — непроверенные строки и переходы. Покрытие 100% не гарантирует отсутствия ошибок: оно показывает, что тесты выполнили все учитываемые строки и ветви.

Для отчёта в браузере выполните:

```bash
python -m coverage html
```

Откройте созданный файл `htmlcov/index.html`.
